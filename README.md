🎵 A Data Science Approach for Analyzing Music Industry Trends
📌 Project Overview

This project focuses on analyzing song popularity using a real-world Spotify dataset. The main objective is to understand how different audio features affect song popularity and to build machine learning models capable of predicting popularity scores.

The project applies data analysis, visualization, and machine learning techniques to identify patterns in music trends and evaluate the performance of different predictive models.

📊 Dataset Information
Dataset Source: Kaggle Spotify Dataset
Dataset Size: Approximately 3000 songs
Features Used
Tempo
Energy
Danceability
Loudness
Popularity
🎯 Objectives
Analyze the relationship between audio features and song popularity
Perform exploratory data analysis (EDA) on music data
Apply multiple machine learning algorithms for prediction
Compare the performance of different models
Identify the most accurate and effective model
⚙️ Tools & Technologies
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
TensorFlow / Keras
Jupyter Notebook
🧠 Machine Learning Models Used

The following machine learning models were implemented and evaluated:

Linear Regression
Decision Tree Regressor
Random Forest Regressor
Neural Network (TensorFlow/Keras)
📈 Results & Findings
Random Forest achieved the best performance among all models due to its ability to handle complex feature relationships.
Decision Tree suffered from overfitting and produced weaker generalization results.
Linear Regression and Neural Network delivered moderate prediction accuracy.
The analysis revealed that audio features alone are not enough to completely predict song popularity, indicating the influence of external factors such as marketing, social media trends, and listener behavior.
🔍 Key Insights
Songs with higher energy and danceability often showed higher popularity trends.
Loudness and tempo had varying impacts depending on the genre and audience preference.
Popularity prediction in the music industry is a complex problem influenced by multiple hidden factors.

📚 Conclusion

This project demonstrates how data science and machine learning can be applied to analyze music industry trends and predict song popularity. While machine learning models can capture patterns from audio features, real-world popularity depends on many external and dynamic factors beyond the dataset.
