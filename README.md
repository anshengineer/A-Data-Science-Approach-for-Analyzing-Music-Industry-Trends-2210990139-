A-Data-Science-Approach-for-Analyzing-Music-Industry-Trends-
This project focuses on analyzing song popularity using a real-world Spotify dataset. The goal is to understand how different audio features influence the popularity of songs and to build machine learning models that can predict song popularity.

📊 Dataset Source: Kaggle (Spotify Dataset) Size: ~3000 songs Features: Tempo Energy Danceability Loudness Popularity

🎯 Objectives Analyze the relationship between audio features and song popularity Apply machine learning models for prediction Compare performance of different models Identify the most effective model

⚙️ Tools & Technologies Python Pandas NumPy Matplotlib & Seaborn Scikit-learn TensorFlow / Keras Jupyter Notebook

🧠 Machine Learning Models Used Linear Regression Decision Tree Random Forest Neural Network

📈 Results Random Forest performed the best among all models Decision Tree showed poor performance due to overfitting Linear Regression and Neural Network gave moderate results Audio features alone are not sufficient to fully predict popularity

🔮 Future Scope Include user behavior and social media data Improve model performance with larger datasets Apply advanced deep learning models
